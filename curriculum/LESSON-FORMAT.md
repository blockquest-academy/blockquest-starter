# Формат файла урока `lesson.json`

Один файл на урок: `curriculum/season-N/lesson-NN/lesson.json`. Его читают расширение VS Code (панель «Задания», проверки, домашка), а позже — игра, кузнец и доска заказов. Текст для ученика живёт только здесь; методичка преподавателя остаётся прозой в `teacher/lesson-guides/`.

Все тексты — словари по языку: `{ "ru": "…" }`. Второй язык добавляется ключом (`"it"`), код и проверки от языка не зависят.

## Урок

| Поле | Что это |
|---|---|
| `schema` | версия формата, сейчас `1` |
| `id` | `season-1/lesson-03`, совпадает с папкой |
| `number` | номер урока, как в `teacher/lessons/current.md` |
| `title`, `tagline` | название и одна строка о сути |
| `minutes` | длительность занятия |
| `file` | главный учебный файл урока |
| `concept` | конструкция урока одной фразой |
| `perk` | что нового появилось в игре на этом уровне |
| `tracks` | названия дорожек: `main` маршрут, `side` для быстрых, `home` домашка |
| `warmup` | вопросы разминки на бумаге |
| `steps` | шаги по порядку |

## Шаг

| Поле | Что это |
|---|---|
| `id` | короткий латинский ключ, уникален внутри урока |
| `track` | `main`, `side` или `home` |
| `kind` | `play` действие в игре, `code` правка файла, `talk` объяснить устно (без заданий на бумаге) |
| `required` | обязательный шаг маршрута; необязательные уходят в побочные, если не успели |
| `minutes` | ориентир по плану, например `18–33` |
| `title`, `task` | заголовок и задание: одно действие, повелительное наклонение |
| `where` | `file`, `anchor` (строка-ориентир в файле), `place` — `above`, `below` или без указания |
| `code` | что должно получиться в файле после шага; показывается по кнопке, не сразу |
| `expect` | что покажет игра, когда шаг сделан |
| `explain` | объяснение на пальцах с аналогией: что происходит и почему |
| `hints` | три подсказки от направления к точной правке; открываются по одной |
| `actions` | список коротких действий шага по порядку (одно действие — одна строка, глагол первым); панель показывает их нумерованным списком под целью |
| `check` | как проверяется шаг, см. ниже |
| `smith` | что говорит кузнец (персонаж урока), пока шаг текущий |

## Проверки

- `{"type":"file","file":"student/forge.js","rules":[…]}` — разбор файла без запуска. Правила: `{"matches":"regex","min":3}`, `{"notMatches":"regex"}`, `{"defines":"forge"|"*","exported":false,"minCalls":3}` — объявлена функция и вызвана не меньше N раз, `{"exports":"onHit"}`, `{"topLevelLet":"hits"}` — `let` на верхнем уровне файла.
- `{"type":"run","file":"student/forge.js","fn":"armor","cases":[[[1],2],[[5],10]],"hidden":[[[7],14]]}` — файл загружается в отдельном процессе Node, функция вызывается с аргументами, ответы сравниваются. `hidden` — скрытые числа, чтобы нельзя было подогнать ответы. Варианты: `"sequence":[1,2,3]` — три вызова подряд, ответы должны заканчиваться на 1, 2, 3; `"expect":"defined"` — функция есть и что-то возвращает; `"expect":"number","args":[[1],[2]]` — возвращает число на этих аргументах.
- `{"type":"game","key":"lesson-03.received","min":1,"fallback":"self"}` — свидетельство из игры в `.academy/progress.json` (раздел `game`). Пока игра его не записала, с `fallback: "self"` ученик отмечает шаг сам.
- `{"type":"self","label":{"ru":"…"}}` — самооценка галочкой.

Проверка `run` и `file` работают без игры, поэтому годятся для домашки. Проверка `game` появляется, когда игра пишет прогресс в файл.

## Прогресс

`.academy/progress.json` в папке проекта. Расширение пишет туда результаты шагов и открытые подсказки, игра — свидетельства (`game`). Файл едет вместе с работой ученика и сохраняется при обновлении Академии.

```json
{
  "schema": 1,
  "lessons": { "season-1/lesson-03": { "steps": { "armor": { "done": true, "at": "2026-11-01T12:00:00Z", "via": "check" } }, "hints": { "armor": 2 } } },
  "game": { "lesson-03": { "received": true, "weaponHits": 3, "orders": { "armor": "passed" } } }
}
```

Как писать тексты шагов, чтобы ребёнок понял с первого раза: [TASK-CARD-STYLE.md](TASK-CARD-STYLE.md).
