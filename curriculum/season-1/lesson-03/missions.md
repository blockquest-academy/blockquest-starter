# Кузница · твой маршрут

В лаборатории нажми **«Урок 03»**. На северном берегу открылась тропа — у её начала указатель «КУЗНИЦА ↑». Дойди до кузнеца: он выдаст тебе меч, топор и молот. Клавиши **1, 2, 3** выбирают оружие, пробел — удар. Во дворе кузницы монстры тебя не трогают.

Сегодня ты пишешь свою первую функцию в `student/forge.js`. Перед каждой правкой: **предскажи → напечатай → сохрани → проверь → объясни**. Подсказки открывай по одной.

Хранитель из урока 02 и твоё правило из урока 01 продолжают работать.

## Три раза одно и то же · 8–18 минут

Открой `student/forge.js`. Урон трёх оружий считается одной формулой, написанной три раза:

```js
export const swordDamage = 2 * 4 + 2;     // Меч · железо, сила 2
export const axeDamage = 5 * 4 + 2;       // Топор · сталь, сила 5
export const hammerDamage = 9 * 4 + 2;    // Молот · кристалл, сила 9
```

Кузнец улучшил горн: теперь `+ 5` вместо `+ 2`. Поправь все три строки, сохрани и сравни «Игра получила». Пропустил одну строку? Одно оружие осталось слабым. А если оружия будет двадцать?

## EASY · Рецепт кузнеца · 18–35 минут

Напиши формулу один раз и дай ей имя. Это функция:

```js
function forge(metal) {
  return metal * 4 + 2;
}
export const swordDamage = forge(2);
export const axeDamage = forge(5);
export const hammerDamage = forge(9);
```

`function` — объявляем рецепт. `forge` — имя. `metal` в скобках — что кладём в рецепт при вызове. `return` — что рецепт отдаёт обратно. `forge(5)` кладёт 5 в `metal` и даёт 22. У `forge` нет `export`: её вызываешь ты сам, а игра получает готовые числа.

Сохрани, выбери оружие клавишей 1, 2 или 3 и ударь им хранителя, слизня или манекен у кузницы.

<details><summary>Подсказка 1</summary>Три строки считают одно и то же разными числами. Что в них одинаковое, а что меняется?</details>
<details><summary>Подсказка 2</summary>Над оружием напиши function forge(metal) { return metal * 4 + 2; } — четыре строки со скобками. Затем справа от = у swordDamage напиши forge(2).</details>
<details><summary>Подсказка 3</summary>function forge(metal) { return metal * 4 + 2; } и три вызова: forge(2), forge(5), forge(9). Сохрани: «Игра получила» покажет 10, 22, 38.</details>

Проверка: три числа в «Игра получила», меч, топор и молот на стойке у кузницы, удар засчитан.

**Сломай нарочно.** Убери `return` и сохрани: что скажет игра про урон меча? Верни строку. Напиши `forge()` без числа: что получилось? Это `NaN` — «не число»: рецепт получил пустую коробку.

**Одно число меняет всё.** Поменяй `+ 2` на `+ 5` только внутри функции. Что изменилось у меча, топора и молота? Сколько ударов молотом теперь нужно хранителю?

## Игра вызывает твою функцию · 35–45 минут

Манекен у кузницы вызывает функцию `onHit` при каждом ударе. Напиши её ниже строки «ЗАКАЗЫ КУЗНЕЦА»:

```js
export function onHit() {
  return "Ай!";
}
```

У неё есть `export`: её вызывает игра, а не ты. Ударь манекен пробелом — над ним появится то, что вернула функция. Вспомни урок 01: `crystalRule(crystals)` тоже вызывала игра на каждом кристалле.

## Счётчик и память · 50–62 минуты

Пусть манекен считает удары. После `return` функция забывает всё, поэтому коробка должна жить снаружи:

```js
let hits = 0;
export function onHit() {
  hits = hits + 1;
  return hits;
}
```

Ударь манекен три раза: 1, 2, 3. `hits = hits + 1` меняет коробку при каждом вызове — поэтому `let`, а не `const`.

**Сломай нарочно.** Замени `let` на `const`: что скажет игра? Перенеси `let hits = 0` внутрь функции: что покажет манекен и почему?

## NORMAL · Заказы кузнеца · 62–72 минуты

На доске два заказа. Кузнец сам проверит твои функции: над манекеном появятся строки «armor(1) → 2 ✔», а в лаборатории таблица «вызов / ждём / получили».

**Броня.** Функция `armor(metal)` возвращает силу металла × 2.

**Потерянный рецепт искры.** Рецепт потерян, осталась таблица: `spark(1) → 10`, `spark(2) → 20`, `spark(3) → 30`. Догадайся, что делает рецепт, и напиши функцию `spark(metal)` с такими же ответами. Кузнец проверит её и на числе, которого нет в таблице.

## CHALLENGE · Молния и счётчик · 72–85 минут

**Потерянный рецепт молнии.** Таблица: `lightning(1) → 5`, `lightning(2) → 7`, `lightning(3) → 9`, `lightning(10) → 23`. Сначала посмотри, на сколько растёт ответ, когда `metal` растёт на 1. Потом — сколько не хватает. Угадаешь — твой удар станет молнией.

**Счёт ударов.** Счётчик из прошлого шага — второй заказ этой вкладки: после трёх ударов подряд `onHit` должна вернуть 1, 2, 3 (`"Удар 3"` тоже подходит).

<details><summary>Подсказка 2</summary>metal × 2 даёт 2, 4, 6 — а нужно 5, 7, 9. Сколько не хватает каждый раз?</details>

Проверка: молния на стойке и в ударе, манекен досчитал до трёх, доска «4/4».

## Для быстрых

Карточки — во вкладке Challenge, «Для быстрых».

- **Имя оружия.** `weaponTitle(name)` возвращает `"Меч " + name`: `weaponTitle("Гром")` → `"Меч Гром"`. Пробел внутри кавычек обязателен.
- **Здоровье не уходит в минус.** `healthAfterHit(health, damage)` — два входа и одно `if`: `healthAfterHit(50, 20)` → 30, `healthAfterHit(10, 15)` → 0.
- **Рецепт для соседа.** Напиши `secretRecipe(metal)` со своей формулой. В лаборатории видна только таблица ответов для 1–5. Сосед угадывает формулу и пишет такую же у себя — таблицы должны совпасть.
- **Паук у ворот.** У восточных ворот в лес стережёт паук: 120 здоровья и панцирь — меч по нему бьёт вполсилы, топор и молот в полную. До боя посчитай удары каждым оружием (таблица в карточке Easy подскажет). Паук рвётся к тебе и плюёт паутиной: если застрял — Shift. Побеждённый паук роняет ключ от ворот; он пригодится в уроке 04.

## Три вопроса в конце · без AI

1. `function forge(metal) { return metal * 3 + 2; }` — что вернёт `forge(5)`?
2. `function double(x) { x * 2; }` — что вернёт `double(4)`? Почему?
3. `let hits = 0; function onHit() { hits = hits + 1; return hits; }` — вызвали три раза: что вернул третий вызов?

Автопроверка замечает рецепт с тремя вызовами, удар оружием, строки заказов и счётчик на манекене. Прогноз и объяснение обсуждаем с преподавателем.

## Если появилась ошибка

Прочитай подсказку над игрой или в карточке заказа.

- «Жду функцию armor, а в файле есть armr» — опечатка в имени.
- «Есть в файле, но игра её не видит» — нет `export` перед `function`.
- «Функция ничего не вернула — где return?» — нет `return`.
- «Получилось NaN» — в вычислении не число: проверь имя в скобках функции.
- «Жду 7, получил 6» — формула не та: сравни вход и ответ в таблице.
- «Счётчик не запомнил удар» — коробка `let hits` создаётся заново при каждом вызове: вынеси её выше функции.
- «const нельзя изменить» — объяви `hits` через `let`.
- «Тип значения не подходит» — игра на паузе: урон стал текстом, «ничего» или `NaN`. Проверь кавычки, `return` и число в вызове.

Исправляй по одному символу и сохраняй. Вернуть заготовку кузницы: `npm run reset:lesson -- --exercise forge` и подтверждение «да». Предыдущая работа останется в `backups/`.
