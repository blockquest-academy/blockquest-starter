# Лес · твой маршрут

В лаборатории нажми **«Урок 04»**. Ворота на восточном берегу открыты: паук ушёл. За воротами тёмный лес, три фонаря и Древень. Он гонится за тобой по всему лесу, но в круг света фонаря не заходит: там ты в безопасности, но и бить его оттуда нельзя: отдышался — выходи и бей. Выход из леса — тропа на запад, у указателя «← ОСТРОВ».

Шаги урока — в панели **BlockQuest** в VS Code: один шаг за раз, с местом в файле, подсказками и проверкой. Файл урока — `student/forest.js`. Перед каждой правкой: **предскажи → напечатай → сохрани → проверь → объясни**.

Оружие из кузницы уже в руке: клавиши 1, 2, 3. Хранитель, слизни и твоё правило из прошлых уроков работают как раньше.

## Фонари · 08–20 минут

Яркость трёх фонарей считается одной формулой, написанной три раза — как урон оружия в кузнице:

```js
export const lanternSmall = 2 * 20 + 10;     // Малый фонарь · размер 2
export const lanternMedium = 4 * 20 + 10;    // Средний фонарь · размер 4
export const lanternBig = 6 * 20 + 10;       // Большой фонарь · размер 6
```

Напиши рецепт один раз и вызови его трижды:

```js
function glow(size) {
  return size * 20 + 10;
}
export const lanternSmall = glow(2);
export const lanternMedium = glow(4);
export const lanternBig = glow(6);
```

Числа над фонарями и круги света — ответы твоей функции. У `glow` нет `export`: её вызываешь ты, игра получает три числа.

## EASY · проверка

Функция с тремя вызовами, яркости без предупреждений, вход в лес. Поменяй `+ 10` на `+ 30` внутри функции: все три круга выросли сразу. Верни.

## NORMAL · Фазы Древня · 20–62 минуты

Древень зовёт твою функцию при каждом ударе и передаёт своё здоровье. Ответ — одно слово в кавычках: `"calm"`, `"angry"` или `"giant"`.

Шаг 1 — одно слово:

```js
export function treantPhase(health) {
  return "calm";
}
```

В карточке «Фазы Древня» таблица: первые две строки ✔. Игра уже проверила функцию на шести числах.

Шаг 2 — два случая. Злость на 60 и ниже:

```js
if (health > 60) {
  return "calm";
} else {
  return "angry";
}
```

Шаг 3 — три случая. Великан на 30 и ниже:

```js
if (health > 60) {
  return "calm";
} else if (health > 30) {
  return "angry";
} else {
  return "giant";
}
```

Цепочка читается сверху вниз, игра останавливается на первом верном условии. Граница: 61 — ещё спокойный, 60 — уже злой. `>` значит «строго больше».

Перед каждым ударом мечом скажи вслух, какая будет фаза: 61 и 60, 31 и 30. Меч отнимает по 10, и ты увидишь каждую фазу. Молотом (38) Древень из 140 падает в 102, 64 и 26 — «злой» проскакивает.

## CHALLENGE · Помощник внутри · 68–85 минут

Условию можно дать имя. Сравнение `health <= 30` — это значение да/нет, как `true` и `false` в уроке 02:

```js
function isDanger(health) {
  return health <= 30;
}
```

Внутри `treantPhase`: `if (isDanger(health)) { return "giant"; }`. Помощника вызываешь ты, поэтому `export` ему не нужен.

**Для быстрых.** `treantSays(phase)` — слова Древня на каждую фазу. Текст сравнивают через `===`: `if (phase === "giant") { return "Я ВЫРОС!"; }`. Свои границы: поменяй 60 и 30, предскажи и проверь в бою, потом верни. Долг кузнецу из урока 03 — молния — тоже в панели.

## Расскажи · 86–90 минут

Глядя в свой файл, объясни учителю или соседу: кто вызывает `treantPhase` и зачем ей `export`; какая фаза при 61 и при 60 и почему; что вернёт `isDanger(30)` и какого это типа. Ничего писать не нужно.
