# Твой первый остров

Открой эту папку в VS Code. В терминале выполни:

```sh
npm ci
npm run dev
```

Открой адрес из терминала. Нужны Node.js 22.12+ и npm; если не запускается — позови преподавателя.

Сначала поиграй: WASD / стрелки — движение, пробел — оттолкнуть врагов, Shift — рывок. Собери кристаллы и вернись к порталу слева. После первого кристалла появится «Стать разработчиком».

Твой код находится в файлах папки `student/`:

- **`student/config.js`** — урок 01. Начни с одного числа. Скорость, здоровье, скорость врагов, награда и цель. Сохрани и проверь в игре. Служебные слова уже подготовлены. Скорости 15 и 50 тоже работают; цель портала — 1–22.
- **`student/rules.js`** — урок 01, этап Normal. Добавь одно условие внутрь готовой оболочки и создай щит. На Challenge придумай свой вариант с другим порогом или лечением.
- **`student/guardian.js`** — урок 02. Создай хранителя секретного кристалла: имя (текст), здоровье и урон (числа), оглушается ли он (`true` или `false`). Затем посчитай урон и награду своими именами через `const` и `let`. Бонус: правило ярости в готовой оболочке `guardianMood` — когда раненый хранитель злится.
- **`student/monsters.js`** — урок 02. Здоровье обычных слизней и жуков: импульс ранит их, побеждённые возвращаются через 8 секунд.
- **`student/forge.js`** — урок 03. Кузница на северном берегу: твоя функция считает урон меча, топора и молота, а заказы кузнеца проверяют функции, которые ты пишешь сам.

Урок выбирается кнопками **«Урок 01» / «Урок 02» / «Урок 03»** в лаборатории. Хранитель появляется в центре острова, когда выбран урок 02. Сохранение `guardian.js` возрождает его с новыми свойствами. В уроке 03 на северном берегу открывается тропа к кузнице: дойди до кузнеца — он выдаст меч, топор и молот (клавиши 1, 2, 3), а манекен рядом проверит твои функции. Если над игрой появилось «Тип значения не подходит», игра стоит на паузе: прочитай, какой тип ты написал и какой нужен, исправь указанную строку и сохрани.

Главное: **предскажи → измени → сохрани → проверь → объясни**. После VS Code нажми «Продолжить». Настройки сохраняют текущий остров; изменение здоровья даёт полный запас. После изменения способности нажми ↻ для проверки с начала. Щит и лечение повторяются на новых кристаллах, для которых условие верно. Два щита не складываются. Правило получает только crystals — общее число находок.

Задания и подсказки — в лаборатории и карточках: [урок 01](curriculum/season-1/lesson-01/missions.md), [урок 02](curriculum/season-1/lesson-02/missions.md), [урок 03](curriculum/season-1/lesson-03/missions.md). Записывай опыты в журнал: [урок 01](curriculum/season-1/lesson-01/experiment-log.md), [урок 02](curriculum/season-1/lesson-02/experiment-log.md), [урок 03](curriculum/season-1/lesson-03/experiment-log.md). В Challenge можно скопировать запрос для AI, выбрать идею, самому напечатать условие и проверить его. Без AI помогает напарник или преподаватель.

↻ сохраняет код и начинает попытку заново. Возврат только заготовки правила: `npm run reset:lesson -- --exercise rules`, затем «да». Только хранитель: `--exercise guardian`, только слизни: `--exercise monsters`. Все начальные файлы: `npm run reset:lesson`. Старая работа останется в `backups/`.

Галочка «Проверил и могу объяснить» — твоя самооценка после проверки. Вступление можно повторить через справку. Это обычная папка проекта без технических ограничений доступа к файлам.


## Обновления игры

Останови dev-сервер. В VS Code выбери Terminal → Run Task → **BlockQuest: обновить Академию**. Можно выполнить в терминале:

```sh
npm run academy:update
```

Обновление сохраняет твой код в student/ и выбранный преподавателем урок. Новые заготовки добавляются, если таких файлов ещё нет. Перед заменой сохраняется резервная копия. После завершения снова запусти npm run dev и обнови страницу игры.

Проверка без установки: npm run academy:update -- --check. Отмена последнего обновления: npm run academy:rollback. Если установщик нашёл собственные изменения движка, покажи сообщение преподавателю: файлы остаются на месте.

Выпуски доступны на [странице обновлений](https://github.com/blockquest-academy/blockquest-starter/releases). Установить заранее скачанный пакет можно через npm run academy:update -- --file "путь-к-пакету.json.gz". Для скачивания публичного обновления аккаунт GitHub не нужен; установка новых зависимостей требует интернета или готового кеша.
