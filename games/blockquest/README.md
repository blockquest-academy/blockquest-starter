# BlockQuest · Crystal Island

Полная top-down игра первого учебного этапа. Запуск из корня проекта: `npm ci` → `npm run dev`.

Исследуйте остров, собирайте кристаллы, избегайте слизней и вернитесь в заряженный портал. Победа требует нужного числа кристаллов **и** возвращения к арке. Здоровье 0 — поражение. Новая попытка всегда доступна через ↻.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | Движение, одинаковая скорость по диагонали |
| Пробел | Импульс радиусом 96 px: отталкивает и оглушает слизней на 2,2 с, перезарядка 0,85 с |
| Shift + направление | Рывок на 0,17 с со скоростью ×2,8, перезарядка 2 с, защита от урона |
| Esc | Пауза / продолжить |

Слизни замечают героя в радиусе 145 px; вне его патрулируют. Быстрый жук патрулирует остров и преследует героя в 1,4 раза быстрее слизня. Контакт с любым монстром наносит 20 урона и даёт 1,2 с защиты от следующего удара. Импульс оглушает и отталкивает оба вида. Вода, стволы деревьев и камни непроходимы. Все 22 кристалла доступны из лагеря. Тени, искры, покачивание кристаллов и анимации отражают состояние игры.

## Student API урока 01

Первый файл: `student/config.js`. Пять именованных числовых экспортов. Значение скорости 3 означает 180 px/с при обычной ходьбе. Монстры с параметром 2 преследуют со скоростью 96 px/с и медленнее патрулируют. Числа выбраны для простоты первого урока, ученикам перевод в пиксели не нужен.

Второй файл — `student/rules.js`: готовая оболочка `crystalRule(crystals)` вызывается при каждом новом подобранном кристалле. Получает только общее число crystals. Одно условие возвращает `"shield"` (защита на один удар) или `"heal"` (до +40 здоровья, не выше максимума). `undefined` означает, что бонуса пока нет. Обе команды могут срабатывать повторно по условию. Пока щит надет, новая команда щита игнорируется; после потери он может появиться на следующей находке, где условие верно. Лечение на каждой подходящей находке восстанавливает до 40 здоровья. Один и тот же кристалл не срабатывает дважды. Пустое правило оставляет базовую игру полностью играбельной. Ошибка выполнения или неизвестная команда дают подсказку, не прерывая сбор.

При сохранении правило применяется без сброса острова, игра ставится на паузу. Само сохранение не выдаёт способность; нужна следующая новая находка. Для проверки границы условия с начала используется ↻. Автопроверка учитывает самое первое срабатывание, проверку щита ударом и собственный вариант с победой. Повторные активации сохраняют первое доказательство и не подменяют новую авторскую способность. Для новых команд позже дополняется обработка в движке и визуальная обратная связь; формат ученического правила остаётся тем же: одно crystals и имя команды. `ui/ai-activity.js` содержит копируемый запрос и журнал для обсуждения с внешним AI или напарником; API к моделям нет.

`engine/game.js::applyConfig` применяет новые правила с сохранением мира; здоровье при изменении восстанавливается. На высоких скоростях симуляция использует ограниченное число подшагов для проверки подбора и урона. `world/island.js` дополнительно ограничивает число шагов движения, чтобы экстремальные значения не зависали.

`ui/learning.js` хранит этап знакомства и историю маршрутов; `ui/missions.js` описывает цели, три подсказки и проверки по конфигурации и игровым действиям. `ui/config-errors.js` загружается раньше игры и объясняет синтаксическую ошибку даже до первого запуска.

`engine/config.js` проверяет значения и возвращает предупреждения. `engine/game.js` содержит независимую от браузера модель. `world/island.js` — карту и движение с небольшими шагами, предотвращающими проход сквозь препятствия. `engine/renderer.js` рисует оригинальные пиксельные объекты и сортирует их по глубине. `main.js` связывает модель с интерфейсом, клавиатурой и HMR.

Проект можно использовать отдельно от будущих сезонов: в текущем репозитории только BlockQuest. Переносите весь текущий корень с package.json, package-lock.json, vite.config.js, student/, games/blockquest/, public/ и index.html; зависимости от других игр отсутствуют. Для материалов и сброса сохраните также curriculum/ и scripts/.

Ученик пишет одно условие внутри готовой оболочки; пока не создаёт функции с нуля, блоки, врагов или карту. Эти учебные точки расширения относятся к следующим фазам и ещё не реализованы. Импульс и рывок — готовая часть игрового опыта, не учебный API будущих уроков.

Рекомендуемые скорости 1–8 не являются техническим пределом: можно сравнить 15 и 50. Технические границы скоростей 0–100; здоровье 1–1 000 000, награда 0–1 000 000, цель 1–22. Некорректные значения получают fallback с объяснением. Все числа в лаборатории читаются из реально применённой конфигурации.
