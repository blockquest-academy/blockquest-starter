# Контекст урока 04 — Лес

Контекст AI-наставника; общие правила находятся в корневом `AGENTS.md`. Здесь нет преподавательских решений. Методичка на 90 минут — отдельно в `teacher/lesson-guides/lesson-04.md`; она не включается в ученические копии.

Игра: BlockQuest — Crystal Island, сезон 1. Ученики 13–15 лет прошли уроки 01–03: меняли числа в `student/config.js`, написали одно условие в `student/rules.js`, создали хранителя в `student/guardian.js` (три типа значений, `const`, арифметика), в `student/forge.js` написали первую функцию `forge(metal)` с тремя вызовами, функцию `onHit`, которую вызывает игра, и заказы `armor`, `spark`; счётчик с `let` снаружи функции и молнию часть учеников не закончила. Цель урока 04: сравнения и граница (`>` против `>=`), цепочка `if / else if / else`, порядок веток сверху вниз, сравнение как значение да/нет, которое возвращает своя функция-помощник. Разминка повторяет функцию: `glow(size)` ученик пишет и вызывает сам, `export` появляется только у функции, которую вызывает игра.

Учебный файл урока — **`student/forest.js`**. Файлы уроков 01–03 остаются рабочими: оружие из кузницы в руке (в уроке 04 его выдавать заново не нужно), хранитель в центре острова, правило кристаллов действует. В `student/` шесть файлов: `config.js`, `rules.js`, `guardian.js`, `monsters.js`, `forge.js`, `forest.js`. Шаги урока с проверками ученик видит в панели BlockQuest в VS Code (расширение); в лаборатории игры — карточки «Фонари», «Фазы Древня», «Помощник внутри», «Слова Древня» с таблицами.

## Последовательность внутри урока

1. **Войди в лес (0–6 минут).** В лаборатории выбран «Урок 04»; ворота на восточном берегу открыты, паук ушёл. Герой входит в проём — вместо острова тёмный лес: три фонаря с числами 50, 90, 130 над ними и пунктирными кругами света на земле, справа у поляны Древень с подписью «Древень · спокойный». Выход — тропа на запад у указателя «← ОСТРОВ». Три вопроса разминки на функции — вслух, ничего на бумаге.
2. **Фонари: функция glow (6–18 минут).** В `forest.js` яркость трёх фонарей считается формулой `размер × 20 + 10`, написанной три раза. Ученик пишет `function glow(size) { return size * 20 + 10; }` над фонарями и заменяет три вычисления вызовами `glow(2)`, `glow(4)`, `glow(6)`. Числа не меняются — и это правильно. Опыт: `+ 30` внутри функции — все три круга выросли.
3. **Древень спрашивает фазу (18–26 минут).** `export function treantPhase(health) { return "calm"; }` ниже строки «ФАЗЫ ДРЕВНЯ». В карточке «Фазы Древня» таблица из шести строк: 100 и 61 ✔, остальные ✘. Связь с `onHit`: функцию вызывает игра, поэтому `export`.
4. **Два случая: if и else (26–45 минут).** `if (health > 60) { return "calm"; } else { return "angry"; }`. Таблица: четыре строки ✔. В бою мечом (10 урона) на восьмом ударе (140 → 60) Древень краснеет, подпись «злой», бегает быстрее героя, бьёт сильнее. Граница 61 / 60.
5. **Перерыв (45–50 минут).**
6. **Три случая: else if (50–60 минут).** `else if (health > 30) { return "angry"; } else { return "giant"; }`. Таблица вся ✔. При 30 и ниже Древень вырастает в полтора раза, подпись «великан», удар вдвое сильнее.
7. **Проверь границу в бою (60–68 минут).** Перед каждым ударом мечом ученик называет фазу вслух: 61 и 60, 31 и 30. Молотом (38) здоровье 140 → 102 → 64 → 26: «злой» проскакивает — Древень спрашивает фазу только после удара. Ничего не записывается.
8. **Помощник внутри: isDanger (68–80 минут).** `function isDanger(health) { return health <= 30; }` без `export` выше `treantPhase`; внутри: `if (isDanger(health)) { return "giant"; }`. Карточка «Помощник внутри» ✔, таблица фаз остаётся ✔. Сравнение — значение да/нет, как `true`/`false` из урока 02.
9. **Победи Древня (80–86 минут).** В круге света он не нападает; после победы «+80», лес светлеет, через 20 секунд Древень возвращается.
10. **Расскажи, как это работает (86–90 минут).** Устно, глядя в файл: кто вызывает `treantPhase` и зачем `export`; фаза при 61 и 60; что вернёт `isDanger(30)` и какого типа. Без AI.

Если стадия неясна, используй текущий вопрос и попытку ученика. На шаге 2 не предлагай `treantPhase`, пока нет `glow` с тремя вызовами. На шагах 3–6 не вводи `else if` раньше, чем ученик увидел два случая. Не объясняй `===` для текста раньше карточки «Слова Древня» (для быстрых). Заданий на бумаге в уроке нет: прогнозы говорятся вслух. Во время устного итога AI не используется.

## Доступные имена и их действие

Игра читает из `student/forest.js` три числа с `export` и функции фаз. Других имён не выдумывай.

| Имя | Что это | Что видно в игре |
|---|---|---|
| `lanternSmall` | число, целое 0–1000, начало `2 * 20 + 10` = 50 | Число над малым фонарём, радиус круга света |
| `lanternMedium` | число, начало `4 * 20 + 10` = 90 | Средний фонарь на севере поляны |
| `lanternBig` | число, начало `6 * 20 + 10` = 130 | Большой фонарь на юге поляны |
| `glow(size)` | своя функция без `export`, вызывается учеником для трёх чисел выше | Три числа в блоке «Игра получила» и над фонарями; имя может быть другим |
| `export function treantPhase(health)` | игра вызывает при появлении Древня и после каждого удара, передаёт здоровье 0–140; ответ — `"calm"`, `"angry"` или `"giant"` | Подпись над Древнем, цвет листвы и глаз, размер, скорость и урон; таблица «вызов / ждём / получили» на числах 100, 61, 60, 31, 30, 1 и трёх скрытых |
| `isDanger(health)` | помощник без `export`: возвращает `health <= 30` (да/нет), вызывается внутри `treantPhase`; имя может быть другим | Карточка «Помощник внутри» ✔ |
| `export function treantSays(phase)` | для быстрых: получает слово фазы, возвращает текст; сравнение `phase === "giant"` | Облачко Древня, когда герой рядом; карточка «Слова Древня» |

- **Лес** — отдельная карта того же размера за воротами. Вход — проём ворот на восточном берегу (в уроке 04 ворота открыты для всех, ключ от паука не нужен; паук ушёл). Выход — тропа на западном краю леса. Остров замирает, пока герой в лесу; возвращение — в точку перед воротами. ↻ из леса начинает попытку у входа в лес. Темно: видно только в кругах фонарей и рядом с героем. После победы над Древнем лес светлеет на полминуты.
- **Фонарь** светит кругом радиусом в яркость (в пикселях карты); граница круга — пунктир. В круг Древень не заходит и героя в нём не ранит: отходит от круга дальше любого оружия и ждёт. Из круга бить нельзя — над героем «Выйди из круга, чтобы бить». Круг — убежище, чтобы отдышаться, а не укрытие для боя. Яркость 0 — фонарь погас, круга нет. Неверный тип (`"130"`, `undefined`, `NaN`) останавливает игру панелью «Тип значения не подходит» с файлом и строкой, как в уроках 02–03. Дробь и число вне 0–1000 — мягкое предупреждение над кодом; пока оно есть, задания урока 04 не засчитываются.
- **Древень**: 140 здоровья, 80 очков за победу, возвращается через 20 секунд с полным здоровьем. Заметив героя ближе 170, гонится за ним по всему лесу со скоростью героя (спокойный 0,85 от скорости героя, злой 1,15, великан 0,95): убежать нельзя, спасение только в круге света. Урон касания по фазе: спокойный 16, злой 24 (бегает в 1,5 раза быстрее), великан 32 (в полтора раза больше). Удары его не оглушают: погоня не прерывается. Удар оружием отнимает урон из `forge.js`: мечом 10, топором 22, молотом 38 (с заготовкой урока 03). Над Древнем после удара «-38 · осталось 102». Молотом четыре удара, топором семь, мечом четырнадцать.
- **Фаза** решается только функцией ученика. Без `treantPhase` Древень всегда спокоен, без предупреждения — карточка говорит «Жду функцию treantPhase». Ответ не из трёх слов (`"Calm"`, `"mad"`, число) — предупреждение над кодом «Древень понимает только "calm", "angry" или "giant" в кавычках», фаза спокойная. Нет `return` — «treantPhase(62) ничего не вернула — где return?». Ошибка внутри — «Не удалось выполнить treantPhase в student/forest.js: имя helth не найдено». Смена фазы: вспышка, надпись «ЗЛОЙ · "angry"» над Древнем, подсказка внизу «Древень: "calm" → "angry" при здоровье 60».
- **Таблица фаз** пересчитывается при каждом сохранении, как заказы кузнеца: строки ✔/✘, фраза «treantPhase(60): жду "angry", получил "calm"», скрытое число — «Проверка на другом числе — treantPhase(45): …». Функция без `export` — «есть в файле, но игра её не видит»; опечатка в имени — «Жду функцию treantPhase, а в файле есть treantPhas».
- **Помощник внутри** засчитывается, если в файле есть своя функция без `export`, вызванная внутри `treantPhase` (по тексту файла). Помощник, объявленный, но не вызванный внутри, не засчитывается.
- **Слова Древня**: если `treantSays` возвращает непустой текст — он в облачке; иначе слова по умолчанию («Кто шумит в моём лесу?», «Ты меня разозлил!», «Я РАСТУ!»). Карточка проверяет, что для каждого из трёх слов функция вернула текст.
- Кузница продолжает работать: сохранение `forge.js` перековывает оружие и проверяет заказы, молния из урока 03 засчитывается и здесь.

## Ошибки, которые урок использует для обучения

- `>=` вместо `>` → строка 60 ✘: «жду "angry", получил "calm"» — граница.
- Ветки в другом порядке (сначала `health > 30`) → строки 100 и 61 ✘ — игра идёт сверху вниз и останавливается на первом верном.
- Только `if / else` → строки 30 и 1 ✘ — третьего случая нет.
- `"Calm"` или `"mad"` → предупреждение о трёх словах; `return health > 60;` → «вернула true» — да/нет вместо слова.
- Нет `return` в ветке → «ничего не вернула — где return?»; нет `export` → «есть в файле, но игра её не видит».
- `=` вместо `===` в `treantSays` → ответ всегда один или панель «Код не выполнился».
- Убрать `return` из `glow` → панель о типе («непонятное значение»); `glow()` без числа → «число NaN».

Не исправляй ошибку молча. Назови строку, объясни сообщение, предложи одну проверку: подставить число в условие и ответить «верно или нет». Ученик исправляет сам.

## Что проверяет игра

Easy: своя функция без `export`, вызванная не меньше трёх раз, яркости без предупреждений, после сохранения герой вошёл в лес. Normal: `treantPhase` проходит все шесть строк и три скрытых числа. Challenge: своя функция без `export` вызвана внутри `treantPhase` и таблица фаз вся ✔. `treantSays`, свои границы, круг света и долг кузнецу в счёт 3 / 3 не входят. В панели BlockQuest каждый шаг проверяется отдельно: таблица фаз по шагам (одно слово — две строки; два случая — четыре; три — шесть), помощник — по тексту файла, вход в лес, граница в бою, победа и устный итог — самоотметка. Объяснение и прогноз вслух проверяет преподаватель.

## Что пока не изучено

Логические операторы `&&`, `||`, `!`; циклы; массивы; объекты (`return { color: "gold", size: 2 }` — тема урока 05); стрелочные функции; `switch`; несколько параметров в основных функциях; вызов функции до её объявления. Изменение движка, карты, Древня и интерфейса — не учебная задача. Идеи вроде «четвёртая фаза в игре», «второй Древень», «фонарь, который можно носить» записываем на будущее и подбираем опыт из условий и чисел `forest.js`. AI на этом уроке необязателен; следующие уроки не подготовлены.
