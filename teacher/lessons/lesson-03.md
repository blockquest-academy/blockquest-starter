# Контекст урока 03 — Кузница

Контекст AI-наставника; общие правила находятся в корневом `AGENTS.md`. Здесь нет преподавательских решений. Методичка на 90 минут — отдельно в `teacher/lesson-guides/lesson-03.md`; она не включается в ученические копии.

Игра: BlockQuest — Crystal Island, сезон 1. Ученики 13–15 лет прошли уроки 01 и 02: меняли числа в `student/config.js`, написали одно условие в `student/rules.js`, создали хранителя в `student/guardian.js` (имена, значения, три типа, `const`, арифметика; `let` и правило ярости прошли бегло). Цель урока 03: написать первую функцию самостоятельно и понять, зачем она нужна — один рецепт вместо повторов; что такое параметр, `return` и вызов; что функцию может вызывать игра; что для памяти между вызовами нужна коробка `let` снаружи функции.

Учебный файл урока — **`student/forge.js`**. Файлы уроков 01–02 остаются рабочими: щит или лечение из `rules.js` действуют, хранитель из `guardian.js` стоит в центре острова, слизни берут здоровье из `monsters.js`. В `student/` пять файлов: `config.js`, `rules.js`, `guardian.js`, `monsters.js`, `forge.js`.

## Последовательность внутри урока

1. **Разминка (0–8 минут).** Три вопроса на типы значений на бумаге. Игра: в лаборатории выбран «Урок 03», на северном берегу открылась тропа к кузнице; у начала тропы указатель «КУЗНИЦА ↑». У кузницы кузнец с облачком, наковальня, доска «ЗАКАЗЫ 0/4», манекен. Ученик идёт к кузнецу по тропе: при первой встрече кузнец выдаёт меч, топор и молот («Держи: меч, топор, молот!»). После этого клавиши 1, 2, 3 выбирают оружие, в углу видно «1 · Меч · урон 10». До встречи удар — обычный импульс урока 02. Во дворе кузницы перемирие: слизни и жуки туда не заходят и героя не трогают.
2. **Три раза одно и то же (8–18 минут).** В `forge.js` урон трёх оружий считается одной формулой `сила × 4 + 2`, написанной три раза. Ученик правит `+ 2` на `+ 5` во всех трёх строках; пропущенная строка видна по урону в «Игра получила» и в бою.
3. **Easy: рецепт кузнеца (18–35 минут).** Ученик печатает `function forge(metal) { return metal * 4 + 2; }` над оружием и заменяет три вычисления вызовами `forge(2)`, `forge(5)`, `forge(9)`. «Сломай нарочно»: убрать `return` — панель «Тип значения не подходит» («непонятное значение — а здесь нужно число»); вызвать `forge()` без числа — «число NaN». Затем выбрать оружие клавишей и ударить хранителя, слизня или манекен.
4. **Игра вызывает твою функцию (35–45 минут).** `export function onHit() { return "Ай!"; }` — удар по манекену показывает ответ над ним. Связь с уроком 01: `crystalRule(crystals)` тоже вызывала игра.
5. **Перерыв (45–50 минут).**
6. **Счётчик и let (50–62 минуты).** `let hits = 0;` выше функции, внутри `hits = hits + 1; return hits;`. Три удара по манекену дают 1, 2, 3. Опыты: `const hits` — игра останавливается панелью «const нельзя изменить»; `let hits = 0` внутри функции — манекен всегда говорит 1.
7. **Normal: заказы кузнеца (62–72 минуты).** `export function armor(metal) { return metal * 2; }` и потерянный рецепт искры `spark(metal)` по таблице 1 → 10, 2 → 20, 3 → 30. Кузнец проверяет сам: над манекеном строки «armor(1) → 2 ✔», в лаборатории таблица «вызов / ждём / получили».
8. **Challenge: молния (72–85 минут).** Потерянный рецепт молнии `lightning(metal)` по таблице 1 → 5, 2 → 7, 3 → 9, 10 → 23. Счётчик из шага 6 — второй заказ этой вкладки. Выполненная молния делает удар молнией.
9. **Три вопроса «что вернёт функция?» и итог (85–90 минут).** Без AI.

Если стадия неясна, используй текущий вопрос и попытку ученика. На Easy не предлагай `export function` и заказы, пока нет `forge` с тремя вызовами. Не объясняй `let` абстрактно: разница видна только на счётчике с манекеном. Во время вопросов на бумаге AI не используется.

## Доступные имена и их действие

Игра читает из `student/forge.js` три числа с `export` и функции заказов. Других имён не выдумывай.

| Имя | Что это | Что видно в игре |
|---|---|---|
| `swordDamage` | число, целое 0–100 000, начало `2 * 4 + 2` = 10 | Урон меча (клавиша 1) |
| `axeDamage` | число, начало `5 * 4 + 2` = 22 | Урон топора (клавиша 2) |
| `hammerDamage` | число, начало `9 * 4 + 2` = 38 | Урон молота (клавиша 3) |
| `forge(metal)` | своя функция без `export`, вызывается учеником для трёх чисел выше | Три урона в блоке «Игра получила»; меч, топор и молот на стойке у кузницы |
| `export function armor(metal)` | заказ «Броня»: вернуть `metal * 2` | Проверка 1 → 2, 5 → 10, 10 → 20 и скрытое число; щит на стойке |
| `export function spark(metal)` | заказ «Потерянный рецепт искры»: по таблице 1 → 10, 2 → 20, 3 → 30 (ответ `metal * 10`) | Искра на стойке; искры при ударе |
| `export function lightning(metal)` | заказ «Потерянный рецепт молнии»: 1 → 5, 2 → 7, 3 → 9, 10 → 23 (ответ `metal * 2 + 3`) | Молния на стойке; удар становится молнией |
| `export function onHit()` | заказ «Счёт ударов»: игра вызывает при каждом ударе по манекену, получает урон оружия; после трёх ударов подряд ответы должны заканчиваться на 1, 2, 3 | Ответ функции над манекеном: «Удар 3» или 3 |
| `export function weaponTitle(name)` | для быстрых: `"Меч " + name` → `weaponTitle("Гром")` = `"Меч Гром"` | Табличка на стойке |
| `export function healthAfterHit(health, damage)` | для быстрых: здоровье после удара, не меньше 0 — одно `if` | Оберег на стойке |
| `export function secretRecipe(metal)` | дуэль: своя формула; в лаборатории видна только таблица ответов для 1–5 | Сосед угадывает формулу по таблице |

- Оружие выдаёт кузнец при первой встрече (герой подошёл к нему ближе чем на 64 пикселя); выдача запоминается в браузере, после ↻ и перезагрузки идти снова не нужно. Удар (пробел) бьёт выбранным оружием: его урон отнимается у хранителя, слизней, жуков и показывается над ними. С оружием `pulseDamage` из `guardian.js` не используется: урон задаёт кузница. Клавиши 1, 2, 3 работают во время игры; в углу карты видно выбранное оружие и урон. Во дворе кузницы (северная поляна вокруг кузнеца и манекена) монстры не преследуют героя и не ранят его.
- Кроме урона у оружия есть характер: меч быстрый (откат 0,55 с) и короткий (дальность 80), топор обычный (0,85 с, 96), молот медленный (1,3 с), но бьёт дальше (112), сильнее отбрасывает и оглушает в 1,6 раза дольше. Число ударов по хранителю от характера не зависит: всё так же здоровье ÷ урон с округлением вверх.
- Сохранение `forge.js` передаёт заказ кузнецу, а сама перековка начинается, когда ученик возвращается в игру и нажимает «Продолжить» (игра всегда на паузе, пока ученик в редакторе). Карточка паузы говорит «Новый рецепт у кузнеца — нажми Продолжить», кузнец в облачке: «Новый файл! Нажми „Продолжить“ — перекую». После этого кузнец раскаляет заготовку на наковальне, бьёт в ритме с искрами, закаляет её паром (около 2,6 секунды), и только потом над манекеном появляются строки проверки, а на стойке — предметы. Урон в «Игра получила» и таблицы в карточках заказов меняются сразу после сохранения. Сколько ударов нужно хранителю: его здоровье разделить на урон, округлить вверх. 60 и 38 — два удара, 60 и 22 — три, 60 и 10 — шесть.
- Функция `forge` — рецепт: `metal` в скобках — что кладём при вызове, `return` — что получаем. Имя может быть другим, игра ищет свою функцию без `export`, вызванную не меньше трёх раз. Ученик меняет число внутри функции — меняются все три урона. Без `return` функция возвращает «ничего» (`undefined`), и панель «Тип значения не подходит» говорит: «непонятное значение — а здесь нужно число». `forge()` без числа даёт `NaN` — «число NaN — а здесь нужно число».
- Функции заказов игра вызывает сама со своими числами, сравнивает ответ с заказом и проверяет на скрытом числе, которого нет в таблице: подогнать ответы по одному нельзя. Результат виден в карточке заказа (таблица «вызов / ждём / получили», ✔ и ✘) и над манекеном построчно. Функции без `export` игра не видит: карточка скажет «есть в файле, но игра её не видит: нужен export перед function». Опечатка в имени: «Жду функцию armor, а в файле есть armr». Нет `return`: «функция ничего не вернула — где return?». Текст вместо числа: «получился текст "2" — а нужно число». `NaN`: «в вычислении не число. Имя из скобок функции написано без ошибок?». Ошибка внутри: «armor(1) остановилась с ошибкой: имя metl не найдено».
- `onHit` игра вызывает при каждом ударе по манекену и передаёт урон оружия (его можно не использовать). Ответ появляется над манекеном; без функции манекен показывает «…». Заказ «Счёт ударов» смотрит на ответы трёх ударов подряд после последнего сохранения: число в конце ответа должно быть 1, 2, 3 (`3`, `"Удар 3"` — подходят). Если ответы одинаковые — «счётчик не запомнил удар. Коробка hits создаётся заново при каждом вызове? Вынеси let hits = 0 выше функции». Сохранение файла и ↻ начинают счёт заново.
- `let hits = 0` снаружи функции живёт, пока файл загружен; `hits = hits + 1` меняет коробку. `const hits` — игра останавливается панелью «const нельзя изменить» со строкой. Сохранение файла обнуляет счётчик.
- Кузнец говорит облачком, когда герой рядом: что ждёт рецептов, что оружие готово, какой заказ не сходится, сколько заказов выполнено (из 4: броня, искра, молния, счётчик). Сохранение файла — удар по наковальне с искрами; ошибка в файле — красный горн; выполненный заказ — фонтан искр и предмет на стойке. Доска «ЗАКАЗЫ n/4» показывает счёт.
- **Паук у ворот** стережёт закрытые ворота «ЛЕС · УРОК 04» на восточном берегу (только в уроке 03). 120 здоровья, касание отнимает 25. Панцирь: меч и обычный импульс бьют вполсилы (над пауком «-5 · панцирь»), топор и молот — в полную: молотом 38 — четыре удара, топором 22 — шесть, мечом 10 — двадцать четыре. Паук рвётся к герою с расстояния и плюёт паутиной: она замедляет героя на 2,4 секунды, рывок Shift рвёт её. Оглушается коротко (0,4 с; молотом 0,8). Побеждённый паук роняет ключ от ворот — ворота откроются в уроке 04; через 25 секунд паук возвращается, бой можно повторить другим оружием. За воротами пока ничего нет.
- **Неверный тип ломает игру — специально**, как в уроке 02: число в кавычках (`swordDamage = "10"`), пропавший `export` у урона, `undefined` или `NaN` от сломанной функции показывают панель «Тип значения не подходит» с файлом и строкой. Игра встаёт на паузу, в ней остаётся последняя рабочая версия.
- **Мягкие предупреждения** над кодом: дробь или число за пределами 0–100 000 — применено ближайшее целое. Пока есть предупреждение, задания урока 03 не засчитываются. Ошибка внутри `onHit` показывается над кодом, но зачёт Easy и Normal не блокирует.

## Ошибки, которые урок использует для обучения

- Нет `return` в `forge` → панель о типе («непонятное значение»); нет `return` в заказе → «функция ничего не вернула — где return?» в карточке.
- `forge()` без числа → `NaN`; опечатка `metl` внутри функции → «имя metl не найдено. Оно написано в скобках функции?».
- Функция без `export` → «есть в файле, но игра её не видит»; опечатка в имени → «Жду функцию armor, а в файле есть armr».
- Неверная формула → таблица с ✘ и фраза «armor(5): жду 10, получил 15»; подогнанные ответы → «Проверка на другом числе — spark(6): жду 60, получил 30. Формула должна работать для любого числа».
- `const hits` с изменением → «const нельзя изменить» со строкой при сохранении; `let hits` внутри функции → «счётчик не запомнил удар».
- Синтаксическая ошибка (скобка, `=`) → файл и строка над игрой: «Проверь скобки функции: ( ) после имени и { } вокруг тела».

Не исправляй ошибку молча. Назови строку, объясни сообщение, предложи одну проверку. Ученик исправляет сам.

## Что проверяет игра

Easy: в файле есть своя функция без `export`, вызванная не меньше трёх раз, урон без предупреждений, оружие получено у кузнеца, и после сохранения был удар оружием по хранителю, пауку, слизню, жуку или манекену. Возвращение к порталу показывает итог экспедиции: заказов выполнено, побеждён ли паук, найден ли секрет хранителя — в зачёт не входит. Normal: функции `armor` и `spark` есть и оба заказа выполнены (все строки ✔, включая скрытое число). Challenge: `lightning` выполнена и `onHit` досчитала до трёх на манекене. Заказы для быстрых и секретный рецепт в счёт 3 / 3 не входят. Отметка понимания — самооценка. Объяснение, прогноз, вопросы на бумаге и дуэль проверяет преподаватель.

## Что пока не изучено

`else` и несколько условий подряд (одно `if` с двумя `return` допустимо только в заказе для быстрых `healthAfterHit`), логические операторы, циклы, массивы, объекты, стрелочные функции, функции с несколькими `return` в основных заказах, вызов функции до её объявления, параметры по умолчанию, события и Canvas. Изменение движка, карты, кузнеца и интерфейса — не учебная задача. Идеи вроде «четвёртое оружие», «лук», «кузнец продаёт» записываем на будущее и подбираем опыт из функций и чисел `forge.js`. AI на этом уроке необязателен; следующие уроки не подготовлены.

Документация контекста остаётся в `teacher/lessons/`. В `student/` только учебные JS-файлы. Преподаватель меняет ссылку в `teacher/lessons/current.md` при переходе к уроку.
